# منصة حمزة المركزية
```
npm install && node server.js
```
## متغيرات البيئة
- `ADMIN_PASSWORD` كلمة المرور (غيّرها!)، `SESSION_SECRET` سر توقيع الدخول.
- `DATA_DIR` مسار التخزين. على Render ركّب Persistent Disk واضبطه عليه (مثال `/var/data`) لتبقى المنصات والملفات.
- `AI_API_KEY` (اختياري) مفتاح ذكاء اصطناعي عام؛ أو ضعه من تبويب المساعد.

## ما الجديد
- حفظ تلقائي: المتصفح يحتفظ بنسخة من كل منصة ويعيدها وحده إذا ضاعت بيانات السيرفر.
- الدخول لا ينتهي بإعادة تشغيل السيرفر (رمز موقّع).
- مفتاح الذكاء الاصطناعي: حقل واحد في تبويب المساعد، يُحفظ ولا يُطلب ثانية (يدعم مفاتيح Google وOpenAI).
- الكونسول: ألوان حسب نوع الرسالة، أزرار نسخ للرمز/الرابط، أشرطة الحمل (أحمر من 85%)، فلترة، وزر "اشرح السبب" بالذكاء الاصطناعي.
- الملفات: قائمة ⋮ لكل ملف (تعديل، نسخ، نقل، تسمية، تنزيل، ضغط، فك...).
- 🐙 GitHub: ألصق رابط المستودع (الفرع/المجلد الفرعي/رمز للخاص اختياري) فتُجلب الملفات وتُثبّت الحزم ويُشغَّل البوت. زر "تحديث من GitHub" للسحب مجدداً.
- مؤشر الشبكة (واي فاي/بيانات) يتحدث كل ثانية.
